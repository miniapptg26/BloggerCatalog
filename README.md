# Каталог блогеров

Статический Telegram Mini App — каталог блогеров на чистом HTML/CSS/JS (без сборщиков и зависимостей). Отредактировали `bloggers.json` — сайт обновился, всё остальное на месте. Работает и в браузере, и внутри Telegram.

## Что это

- **index.html** — страница приложения: липкая шапка со счётчиком, поиск, чипы платформ, сортировка, карточки блогеров, пустой стейт и тост.
- **style.css** — тёмная тема с акцентами `#4d9bff` / `#ff4fa3`, CSS-переменные, поддержка темы Telegram (`--tg-theme-*`), адаптивная сетка карточек (1/2/3 колонки).
- **app.js** — логика: загрузка `bloggers.json`, поиск по имени/нише/платформе, чипы платформ, сортировка (подписчики / имя / новые), форматирование подписчиков, рендер карточек, открытие профиля и копирование ника.
- **bloggers.json** — каталог блогеров. Это единственный файл, который нужно редактировать для наполнения.
- **.nojekyll** — нужен GitHub Pages, чтобы статика публиковалась как есть.
- **.github/workflows/pages.yml** — автоматический деплой на GitHub Pages при пуше в `main`.

## Как заполнять каталог (bloggers.json)

Откройте `bloggers.json` в репозитории на GitHub и нажмите **Edit** (иконка карандаша). После правок нажмите **Commit changes** — сайт пересоберётся автоматом через минуту-две.

Поля каждого блогера:

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| `id` | число | да | Уникальный числовой идентификатор (сортировка «Сначала новые» — по убыванию id) |
| `name` | строка | да | Ник в формате `@username` (копируется по кнопке 📋) |
| `displayName` | строка | да | Имя, которое показывается на карточке |
| `niche` | строка | да | Ниша, например «Технологии и обзоры» |
| `platform` | строка | да | `youtube`, `tiktok`, `telegram`, `instagram` или `twitch` |
| `subscribers` | число | да | Количество подписчиков (форматируется в «млн»/«тыс.») |
| `verified` | boolean | да | `true` / `false` — синяя галочка на карточке |
| `description` | строка | нет | Короткое описание |
| `url` | строка | да | Ссылка на профиль. Если содержит `t.me` — открывается через `Telegram.WebApp.openTelegramLink`, иначе обычным окном |
| `image` | строка | нет | Прямая ссылка **https://…** на фото. Пустая строка `""` — будет эмодзи-аватар |
| `emoji` | строка | нет | Эмодзи-аватар, если нет фото |

Пример одной позиции:

```json
{
  "id": 10,
  "name": "@petr_paint",
  "displayName": "Пётр Художник",
  "niche": "Искусство и творчество",
  "platform": "youtube",
  "subscribers": 450000,
  "verified": false,
  "description": "Скетчи, акварель и уроки рисования для начинающих.",
  "url": "https://youtube.com/@petr_paint",
  "image": "",
  "emoji": "🎨"
}
```

Внимание с запятыми: между элементами массива запятая обязательна, а после последнего `}` запятой быть не должно. Валидность JSON можно проверить локально:

```bash
python3 -m json.tool bloggers.json
```

### Как добавить фото

Поле `image` принимает только прямую ссылку на изображение (https://…). Проще всего:

1. Откройте в репозитории вкладку **Issues → New issue**.
2. Перетащите фото блогера в окно ввода — GitHub загрузит файл и вставит в текст ссылку вида `https://github.com/user/assets/...`.
3. Скопируйте эту прямую ссылку в поле `image`.

Если поле `image` пустое (`""`), аватар показывает эмодзи из поля `emoji` (или заглушку 🎭).

### Платформы

В `app.js` есть словари `PLATFORM_EMOJI`, `PLATFORM_LABELS` и `PLATFORM_COLORS` для платформ `youtube`, `tiktok`, `telegram`, `instagram`, `twitch`. Если укажете другую платформу, бейдж покажет её название как есть, без эмодзи и цвета.

## Как задеплоить на GitHub Pages

Установите и войдите в GitHub CLI:

```bash
gh auth login
```

Из папки проекта выполните:

```bash
git init
git add .
git commit -m "Каталог блогеров"
gh repo create blogger-catalog --public --source=. --push
```

Затем в GitHub: репозиторий → **Settings → Pages**:

- **Source: GitHub Actions** (рекомендуется — workflow `pages.yml` уже лежит в репозитории), или
- **Deploy from a branch** → branch `main` → folder `/ (root)`.

После первого пуша сайт будет доступен по адресу:

```
https://<ваш-логин>.github.io/blogger-catalog/
```

(замените `<ваш-логин>` на имя вашего аккаунта GitHub)

## Как подключить к Telegram

1. В Telegram найдите **@BotFather** и создайте бота: `/newbot`.
2. Далее: `/menu` → **Bot Settings** → **Menu Button**.
3. Укажите URL: `https://<ваш-логин>.github.io/blogger-catalog/` (с вашим логином GitHub).
4. Откройте бота — приложение запустится внутри Telegram как Mini App.

Приложение также работает в обычном браузере по той же ссылке — так удобно тестировать до подключения Menu Button.

## Локальная проверка

```bash
cd blogger-catalog
python3 -m http.server 8000
```

Откройте http://localhost:8000/

## Админ-режим: добавление блогеров прямо из приложения

В приложение встроена админ-панель: с её помощью можно добавлять блогеров в каталог **прямо из Mini App**, не редактируя `bloggers.json` вручную. Запись коммитится в репозиторий GitHub через GitHub REST API (`PUT /repos/{owner}/{repo}/contents/bloggers.json`) — никаких внешних серверов.

### Кто может добавлять

Только пользователь Telegram с username **@g179p** (или числовым id `g179p`). Проверка выполняется по `window.Telegram.WebApp.initDataUnsafe.user` из Telegram WebApp. Для всех остальных кнопка «➕» скрыта (`display: none`), а модальное окно недоступно.

### Как получить fine-grained токен GitHub

1. GitHub → **Settings** → **Developer settings** → **Fine-grained tokens** → **New token**.
2. **Repository access**: **Only select repositories** → выберите свой репозиторий (тот, где лежит приложение).
3. **Permissions** → **Contents**: **Read and write**.
4. Нажмите **Generate token** и скопируйте значение (оно показывается только один раз).

### Как добавить блогера

1. Откройте Mini App с аккаунта **@g179p** — в правой части шапки появится круглая кнопка «➕».
2. Нажмите «➕» — откроется админ-панель.
3. Вставьте **токен**, укажите **owner** (ваш логин GitHub) и **repo** (по умолчанию `blogger-catalog`). Нажмите «Проверить связь» — должно появиться «Связь OK: N блогеров».
4. Заполните поля нового блогера и нажмите «💾 Сохранить в каталог».
5. Через 1–2 секунды страница перезагрузится — новый блогер уже в каталоге (GitHub Pages пересоберётся по workflow `pages.yml`).

`repoOwner` и `repoName` вводятся в админ-панели **один раз**: токен, owner и repo сохраняются в `localStorage` браузера (ключи `gh_token`, `gh_owner`, `gh_repo`) и автоматически подставляются при следующем открытии панели.

### Безопасность токена

- Токен хранится **только в `localStorage` браузера** и не попадает в код, репозиторий или файлы проекта.
- ⚠️ Токен **виден в DevTools** (Application → Local Storage) любому, кто откроет приложение с этого устройства.
- Используйте токен **с правами только на один репозиторий** (Only select repositories → ваш репо) и правами **Contents: Read and write**.
- При подозрении на утечку — **перевыпустите токен** в настройках GitHub (сгенерируйте новый, старый перестанет работать).
