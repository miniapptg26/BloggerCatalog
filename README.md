# Каталог блогеров

Статический Telegram Mini App — каталог блогеров на чистом HTML/CSS/JS (без сборщиков и зависимостей), в ретро-дизайне на основе коричневой палитры. Отредактировали `bloggers.json` — сайт обновился, всё остальное на месте. Работает и в браузере, и внутри Telegram.

## Что это

- **index.html** — страница приложения: липкая шапка со счётчиком, поиск с «✕», сортировка, чипы платформ и ниш, карточки блогеров, пустой стейт и тост.
- **style.css** — ретро-дизайн на основе коричневого: тёмно-коричневая тема (по умолчанию и для Telegram-тёмной) + кремовая тема (.light), serif-заголовки Georgia, янтарные градиентные рамки аватаров, адаптивная сетка карточек (1/2/3/4 колонки).
- **app.js** — логика: загрузка `bloggers.json`, поиск по имени/нише/платформе, чипы платформ и ниш, избранное, «Мне повезёт», детали блогера, сортировка, форматирование подписчиков, открытие профиля, копирование ника.
- **bloggers.json** — каталог блогеров. Это единственный файл, который нужно редактировать для наполнения.
- **.nojekyll** — нужен GitHub Pages, чтобы статика публиковалась как есть.
- **.github/workflows/pages.yml** — автоматический деплой на GitHub Pages при пуше в `main`.

## Пользовательские функции

Личные настройки (избранное, тема) хранятся локально в браузере в `localStorage` и никуда не отправляются; вид «сетка/строки» живёт только в рамках текущей сессии.

| Функция | Описание |
| --- | --- |
| ❤️ **Избранное** | Сердечко на карточке (`🤍`/`❤`) и чип «❤ Избранное» — фильтр + счётчик (число избранных). Хранится в `localStorage` (`blogger_favs`) |
| 🔢 **Счётчики на чипах** | У каждого чипа платформы — бейдж: сколько блогеров на этой платформе во **всём каталоге**; у «❤ Избранное» — число избранных |
| ✕ **Очистка поиска** | Кнопка «✕» внутри поля поиска (видна при непустом запросе): очищает, сбрасывает результаты, возвращает фокус. Поиск с дебаунсом 250 мс |
| ↺ **Сброс фильтров** | Кнопка «↺ Сбросить» рядом с сортировкой (видна, когда активен хотя бы один фильтр) возвращает всё к дефолту |
| 🏷️ **Ниши (второй ряд чипов)** | Уникальные ниши из данных + «Все ниши», комбинируются с платформой (AND) |
| ▦/**☰** **Вид «Сетка/строки»** | Кнопка в шапке переключает карточки: сетка или строки (аватар 72–80px слева, текст и кнопки компактно). Состояние — только сессия |
| 📊 **Статистика** | Кнопка 📊 в шапке: всего блогеров, платформ, суммарно подписчиков («млн/тыс.»), средняя аудитория и ТОП-5 с медалями 🥇🥈🥉 и кнопками «Открыть» |
| 📤 **Экспорт выборки** | Кнопка 📤 копирует в буфер список текущей выборки («Блогеры <дата>», «@<ник> — <ниша> — <подписчики> — <url>») |
| 🔦 **Подсветка поиска** | Совпадения запроса подсвечиваются жёлтым `mark` (безопасно, без `innerHTML`) |
| 🌗 **Тема** | Кнопка «🌙/☀️», выбор в `localStorage` (`blogger_theme`), без мигания при загрузке |
| 🎲 **Мне повезёт** | Кнопка в шапке открывает случайную карточку из текущей выборки |
| 📖 **Детали** | Клик по карточке открывает модалку: квадратный аватар (фото 120px или эмодзи), цветной бейдж платформы, кликабельная ниша (ставится в поиск), подписчики, описание, кнопки «Открыть», «Скопировать ник», «Поделиться» |
| ⏳ **Прелоадер + анимации** | Спиннер при загрузке, стаггер-появление карточек, кнопка «↑» при прокрутке более 600px |

## Наполнение каталога

Каталог наполняется через файл `bloggers.json` на GitHub: откройте файл → **Edit** → добавьте/измените/удалите блок записи по шаблону из раздела ниже → **Commit changes**. В `localStorage` хранятся только избранное и тема.

Поля каждого блогера:

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| `id` | число | да | Уникальный числовой идентификатор (сортировка «Новые» — по убыванию id) |
| `name` | строка | да | Ник в формате `@username` (копируется кнопкой 📋) |
| `displayName` | строка | да | Имя, которое показывается на карточке |
| `niche` | строка | да | Ниша (например «Технологии и обзоры») — чип-фильтр второго ряда |
| `platform` | строка | да | `youtube`, `tiktok`, `telegram`, `instagram` или `twitch` |
| `subscribers` | число | да | Количество подписчиков (форматируется в «млн»/«тыс.») |
| `verified` | boolean | да | `true` / `false` — галочка ✓ и фильтр «Verified» |
| `description` | строка | нет | Короткое описание (полностью — в модалке деталей) |
| `url` | строка | да | Ссылка на профиль. Если содержит `t.me` — открывается через `Telegram.WebApp.openTelegramLink`, иначе обычным окном |
| `image` | строка | нет | Прямая ссылка **https://…** на фото. Пустая `""` — эмодзи-аватар |
| `emoji` | строка | нет | Эмодзи-аватар, если нет фото |

### Пример JSON-блока для вставки

```json
{
  "id": 10,
  "name": "@petr_paint",
  "displayName": "Пётр Художник",
  "niche": "Искусство и творчество",
  "platform": "youtube",
  "subscribers": 450000,
  "verified": false,
  "description": "Скетчи, акварель и уроки рисования для начинающих.",
  "url": "https://youtube.com/@petr_paint",
  "image": "",
  "emoji": "🎨"
}
```

Внимание с запятыми: между элементами массива запятая обязательна, а после последнего `}` запятой быть не должно. Валидность JSON можно проверить локально:

```bash
python3 -m json.tool bloggers.json
```

## Изображения

Поле `image` = **прямая `https://`-ссылка** на картинку (например `https://picsum.photos/seed/.../160/160` или фото на любом хостинге — Imgur и т.п.).

- Аватар подстраивается под круг (`object-fit: cover`): 78×78 в карточке, 120×120 в модалке деталей. У `<img>` заданы `loading="lazy"`, `decoding="async"`, `referrerpolicy="no-referrer"`, `width`/`height` и `alt` = ник.
- До загрузки аватар прозрачный, после загрузки — плавное появление 0.2s; из-за `aspect-ratio 1/1` и фон-заглушки вёрстка не «прыгает».
- Ссылка `http://` (не https) — не грузится, сразу эмодзи-заглушка; ошибка загрузки — тоже эмодзи (повторных попыток нет).
- `"image": ""` (пусто) → эмодзи из поля `emoji`, а если его нет — по платформе (`▶️` youtube, `🎵` tiktok, `✈️` telegram и т.д.).
- Демо: фото у блогеров id 1, 3, 5 (`https://picsum.photos/seed/bloggerN/160/160`), у остальных — эмодзи.

## Платформы

В `app.js` есть словари `PLATFORM_EMOJI`, `PLATFORM_LABELS` и `PLATFORM_COLORS` для платформ `youtube`, `tiktok`, `telegram`, `instagram`, `twitch`. Если укажете другую платформу, бейдж покажет её название как есть, без эмодзи и цвета.

## Как задеплоить на GitHub Pages

Установите и войдите в GitHub CLI:

```bash
gh auth login
```

Из папки проекта выполните:

```bash
git init
git add .
git commit -m "Каталог блогеров"
gh repo create blogger-catalog --public --source=. --push
```

Затем в GitHub: репозиторий → **Settings → Pages**:

- **Source: GitHub Actions** (рекомендуется — workflow `pages.yml` уже лежит в репозитории), или
- **Deploy from a branch** → branch `main` → folder `/ (root)`.

После первого пуша сайт будет доступен по адресу:

```
https://<ваш-логин>.github.io/blogger-catalog/
```

## Как подключить к Telegram

1. В Telegram найдите **@BotFather** и создайте бота: `/newbot`.
2. Далее: `/menu` → **Bot Settings** → **Menu Button**.
3. Укажите URL: `https://<ваш-логин>.github.io/blogger-catalog/` (с вашим логином GitHub).
4. Откройте бота — приложение запустится внутри Telegram как Mini App.

Приложение также работает в обычном браузере по той же ссылке — так удобно тестировать до подключения Menu Button.
