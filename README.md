# Каталог блогеров

Статический Telegram Mini App — каталог блогеров на чистом HTML/CSS/JS (без сборщиков и зависимостей). Отредактировали `bloggers.json` — сайт обновился, всё остальное на месте. Работает и в браузере, и внутри Telegram.

## Что это

- **index.html** — страница приложения: липкая шапка со счётчиком, поиск, сортировка, чипы платформ, карточки блогеров, пустой стейт и тост.
- **style.css** — тёмная тема с акцентами `#4d9bff` / `#ff4fa3` + светлая тема (.light), CSS-переменные, поддержка темы Telegram (`--tg-theme-*`), адаптивная сетка карточек (1/2/3/4 колонки).
- **app.js** — логика: загрузка `bloggers.json`, поиск по имени/нише/платформе, чипы платформ, избранное, «Мне повезёт», детали блогера, сортировка, форматирование подписчиков, открытие профиля, копирование ника и редактор владельца (кнопка 📝, только для `@g179p`) с автосохранением через GitHub API (добавление/удаление записей прямо из приложения) и запасным генератором JSON-блоков.
- **bloggers.json** — каталог блогеров. Это единственный файл, который нужно редактировать для наполнения.
- **.nojekyll** — нужен GitHub Pages, чтобы статика публиковалась как есть.
- **.github/workflows/pages.yml** — автоматический деплой на GitHub Pages при пуше в `main`.

## Пользовательские функции

Без сервера и без админ-панели. Личные настройки (избранное, тема) хранятся локально в браузере в `localStorage` и никуда не отправляются.

### Дополнительные функции

| Функция | Описание |
| --- | --- |
| ❤️ **Избранное** | Сердечко на карточке (`🤍`/`❤`) и чип «❤ Избранное» — фильтр + счётчик. Хранится в `localStorage` (`blogger_favs`) |
| 📊 **Статистика** | Кнопка 📊 в шапке: всего блогеров, платформ, суммарно подписчиков (формат «млн/тыс.»), средняя аудитория и ТОП-5 по подписчикам с медалями 🥇🥈🥉 и кнопками «Открыть» (t.me → openTelegramLink, иначе window.open) |
| 📤 **Экспорт выборки** | Кнопка 📤 в шапке копирует в буфер список текущей отфильтрованной/отсортированной выборки («Блогеры <дата>», строки «@<ник> — <ниша> — <подписчики> — <url>»). Пустая выборка — тост «Нет записей для экспорта» |
| 🔦 **Подсветка поиска** | Совпадения запроса подсвечиваются жёлтым `mark` (безопасно, без `innerHTML`) |
| 🌗 **Тема** | Кнопка «🌙/☀️», выбор в `localStorage` (`blogger_theme`), без мигания при загрузке |
| 🎲 **Мне повезёт** | Кнопка в шапке открывает случайную карточку из текущей выборки |
| 📖 **Детали** | Клик по карточке открывает модалку: квадратный аватар (фото `image` или эмодзи), цветной бейдж платформы, ниша (кликабельная — ставит её в поиск), подписчики, описание, кнопки «Открыть», «Скопировать ник», «Поделиться», «Наверх» и BackButton |
| ⏳ **Прелоадер + анимации** | Спиннер при загрузке, стаггер-появление карточек, кнопка «↑» при прокрутке более 600px |

> В `localStorage` хранятся только личные настройки пользователя (избранное `blogger_favs` и тема `blogger_theme`); при очистке данных сайта они сбрасываются.

## Как заполнять каталог (bloggers.json)

Рекомендуемый способ — с автосохранением через GitHub API (без правки JSON руками); ручные способы остаются как запасные.

### Добавление и удаление записей — через GitHub API (рекомендуемый)

1. Откройте Mini App с аккаунта `@g179p` → кнопка **📝**.
2. В секции **«🔌 GitHub API (автосохранение)»** вставьте fine-grained token, укажите владельца (ваш GitHub-ник) и репозиторий `blogger-catalog` → нажмите **«Проверить связь»** — должен появиться зелёный статус OK.
3. На вкладке **«➕ Добавить запись»** заполните форму → **«💾 Сохранить через API»** — запись коммитится в `bloggers.json` автоматически (commit `Add item via Mini App`).
4. На вкладке **«🗑 Удалить запись»** → **«🗑 Удалить (API)»** у нужной строки (commit `Remove item via Mini App`).
5. Сайт пересоберётся автоматически через GitHub Actions (обычно 30–60 сек).

**Как получить fine-grained token:** GitHub → **Settings → Developer settings → Fine-grained personal access tokens → Generate new token** → **Repository access: Only select repositories** → выберите свой репозиторий → **Permissions → Contents: Read and write** → **Generate** → скопируйте токен.

> ⚠️ Токен хранится только в `localStorage` вашего браузера и виден в DevTools любому, кто откроет приложение. Выдавайте права только на один репозиторий; при утечке — перевыпускайте. В коде и репозитории токен не хранится.

### Способы вручную (запасные, без кода)

- **Способ 1 — вручную на GitHub**: откройте `bloggers.json` → кнопка **Edit** (карандаш) → правки → **Commit changes**. Сайт пересоберётся автоматически через минуту-две.
- **Способ 2 — редактор в приложении (JSON-блоки)**: откройте Mini App с аккаунта `@g179p` → кнопка **📝** → вкладка «➕ Добавить запись» → заполните форму → «📋 Скопировать JSON записи» (вставьте блок на GitHub перед `]`, после предыдущей записи добавьте запятую) или «⬇️ Скачать новый файл» (замените `bloggers.json` целиком: Edit → Ctrl+A → вставить → Commit).

### Добавление и удаление записей — ручное (без кода, запасной способ)

Поля каждого блогера:

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| `id` | число | да | Уникальный числовой идентификатор (сортировка «Новые» — по убыванию id) |
| `name` | строка | да | Ник в формате `@username` (копируется кнопкой 📋) |
| `displayName` | строка | да | Имя, которое показывается на карточке |
| `niche` | строка | да | Ниша, например «Технологии и обзоры» |
| `platform` | строка | да | `youtube`, `tiktok`, `telegram`, `instagram` или `twitch` |
| `subscribers` | число | да | Количество подписчиков (форматируется в «млн»/«тыс.») |
| `verified` | boolean | да | `true` / `false` — галочка ✓ и фильтр «Verified» |
| `description` | строка | нет | Короткое описание (полностью показывается в модалке деталей) |
| `url` | строка | да | Ссылка на профиль. Если содержит `t.me` — открывается через `Telegram.WebApp.openTelegramLink`, иначе обычным окном |
| `image` | строка | нет | Прямая ссылка **https://…** на фото. Пустая строка `""` — будет эмодзи-аватар |
| `emoji` | строка | нет | Эмодзи-аватар, если нет фото |

### Добавление и удаление записей — ручное (без кода)

**Добавить запись — Способ 1 (GitHub, руками):**

1. Откройте `bloggers.json` на GitHub → **Edit**.
2. Скопируйте шаблон блока записи из раздела ниже и вставьте его **перед последней закрывающей скобкой `]`**.
3. После предыдущей записи добавьте запятую — между `}` предыдущей записи и вашим новым `{` должна стоять `,`.
4. **Commit changes** — через минуту-две сайт пересоберётся.

**Добавить запись — Способ 2 (редактор в приложении, запасной способ):**

1. Откройте Mini App с аккаунта `@g179p` — кнопка **📝** в шапке видна только владельцу (проверка `initDataUnsafe.user.username === 'g179p'` или `id === 'g179p'`).
2. Вкладка **«➕ Добавить запись»**: заполните форму (имя, ник, ниша, платформа, подписчики, verified, описание, ссылка, эмодзи).
3. **«📋 Скопировать JSON записи»** — в буфере появляется блок `  {"id": <maxId+1>, ...}` (только заполненные поля). Вставьте его на GitHub перед `]` (после предыдущей записи добавьте запятую).
4. Или **«⬇️ Скачать новый файл»** — скачивается полный `bloggers.json` с новой записью. Замените содержимое файла на GitHub: **Edit → Ctrl+A → вставить → Commit changes**.

**Удалить запись (запасной способ):**

- Через редактор: вкладка **«🗑 Удалить запись»** → у нужной строки нажмите **«⬇️ Без этой записи»** → подтвердите в диалоге → скачанный файл (уже без записи) замените на GitHub, или нажмите **«📋 Скопировать весь JSON»** → Edit → Ctrl+A → вставить → Commit.
- Или вручную: на GitHub в `bloggers.json` удалите блок `{ ... }` нужной записи (и лишнюю запятую) → **Commit changes**.

### Пример JSON-блока для вставки

Шаблон одной записи (поля: `id` — уникальный номер; `name` — ник `@...`; `displayName` — имя; `niche` — ниша; `platform` — одна из `youtube/tiktok/telegram/instagram/twitch`; `subscribers` — число; `verified` — `true`/`false`; `description` — описание; `url` — ссылка; `image` — прямая ссылка на фото или `""`; `emoji` — эмодзи-заглушка):

```json
{
  "id": 10,
  "name": "@petr_paint",
  "displayName": "Пётр Художник",
  "niche": "Искусство и творчество",
  "platform": "youtube",
  "subscribers": 450000,
  "verified": false,
  "description": "Скетчи, акварель и уроки рисования для начинающих.",
  "url": "https://youtube.com/@petr_paint",
  "image": "",
  "emoji": "🎨"
}
```

Внимание с запятыми: между элементами массива запятая обязательна, а после последнего `}` запятой быть не должно. Валидность JSON можно проверить локально:

```bash
python3 -m json.tool bloggers.json
```

### Изображения

Поле `image` = **прямая `https://`-ссылка** на картинку. Как получить ссылку: загрузите фото на любой хостинг (например Imgur), либо в интернете кликните по картинке правой кнопкой → **«Открыть изображение»** → скопируйте адрес из адресной строки.

- Картинка подстраивается под квадрат (`object-fit: cover`): аватар 78×78 в карточке, 120×120 в модалке деталей.
- `"image": ""` (пусто) → показывается эмодзи из поля `emoji`, а если его нет — эмодзи по платформе (`▶️` youtube, `🎵` tiktok, `✈️` telegram и т.д.).
- Битая ссылка (ошибка загрузки) → автоматически подставляется эмодзи-заглушка. Битых картинок не бывает.
- Демо: у блогеров с id 1, 3, 5 заданы примеры `https://picsum.photos/seed/bloggerN/400/400` — замените на свои фото.

### Что хранится

В `localStorage` — только личные настройки пользователя: избранное (`blogger_favs`), тема (`blogger_theme`) и настройки GitHub-подключения для владельца (`gh_token`, `gh_owner`, `gh_repo`). Каталог **нигде не кэшируется**: при каждом открытии `bloggers.json` загружается заново, никаких данных пользователей никуда не отправляется.

### Платформы

В `app.js` есть словари `PLATFORM_EMOJI`, `PLATFORM_LABELS` и `PLATFORM_COLORS` для платформ `youtube`, `tiktok`, `telegram`, `instagram`, `twitch`. Если укажете другую платформу, бейдж покажет её название как есть, без эмодзи и цвета.

## Как задеплоить на GitHub Pages

Установите и войдите в GitHub CLI:

```bash
gh auth login
```

Из папки проекта выполните:

```bash
git init
git add .
git commit -m "Каталог блогеров"
gh repo create blogger-catalog --public --source=. --push
```

Затем в GitHub: репозиторий → **Settings → Pages**:

- **Source: GitHub Actions** (рекомендуется — workflow `pages.yml` уже лежит в репозитории), или
- **Deploy from a branch** → branch `main` → folder `/ (root)`.

После первого пуша сайт будет доступен по адресу:

```
https://<ваш-логин>.github.io/blogger-catalog/
```

(замените `<ваш-логин>` на имя вашего аккаунта GitHub)

## Как подключить к Telegram

1. В Telegram найдите **@BotFather** и создайте бота: `/newbot`.
2. Далее: `/menu` → **Bot Settings** → **Menu Button**.
3. Укажите URL: `https://<ваш-логин>.github.io/blogger-catalog/` (с вашим логином GitHub).
4. Откройте бота — приложение запустится внутри Telegram как Mini App.

Приложение также работает в обычном браузере по той же ссылке — так удобно тестировать до подключения Menu Button.
